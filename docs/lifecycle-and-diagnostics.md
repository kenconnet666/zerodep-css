# 生命周期和定位

组件的 bx 绑定由 Vue / Svelte 生命周期管理。卸载时停止订阅并删除该组件的私有值规则；引用这些私有变量的类与动画在不再依赖任何活动绑定后一起回收。named globalCss 块和普通静态类属于文档 / 请求宿主，不随组件自动删除。

```ts
const stats = cssStats();
// rules：总数；classes：普通类；animations：动画；
// globals：命名全局块；bindings：私有值规则；connected：主标签是否连接。
```

`bindings` 不等于当前 DOM 元素数。列表更换 key 后，旧 frame 仍保留到所属组件卸载，因为返回的 class 字符串可能被其他位置保存。需要长期轮换大量数据时，优先使用有独立生命周期的行组件，避免将所有历史 key 都留在一个永久存在的父组件中。

普通静态类和动画按内容缓存。带实例私有变量的样式只在绑定所有者存活期间有效；可转发给子组件，但不要在所有者销毁后继续使用其 class 字符串。多个活动绑定组成的类会保留到最后一个绑定结束。回收依据明确的绑定引用关系，不按年龄或容量淘汰普通静态样式。批量删除避免每个组都扫描 CSSOM。`disposeCss()` 只用于整个宿主退出；不能在任意路由 / 子组件卸载时调用，以免破坏其他活动组件。

真实 Vite HMR 的模板更新、脚本更新、删除动态声明和修改选择器由 CI 验证。测试使用独立临时应用，不修改用户正在运行的项目；测试结束关闭自己的服务器、浏览器并清理目录。热更新应保留其他组件样式，且不增加重复活动绑定。Vue 与 Svelte 的组件热替换机制不同，不要求它们产生相同数量的历史类。

构建回退提示包含 `文件:行:列`。不支持的绑定作用域在开发构建中附带作者调用位置；生产代码不携带位置字典。source map 保留未修改语句的位置，改写调用中的辅助代码映射到相应原始片段。

当前耗时验收由 CI 执行：真实 HMR、30 次挂卸、列表 key 轮换、200 / 1,000 项性能对照、Nuxt / Kit 的 SSR 与静态部署。按任务命名的 `lifecycle-*`、`browser-*`、`performance-*` artifact 保存计数与计时。时间只供比较和选型，不作为硬阈值；不能把“未重复写 CSSOM”解释为“完全不再执行 JS”。

详细样本与本轮结论见[稳定性与主题交付记录](../.research/stability-and-theme-delivery.md)。

核心源码覆盖率由 `pnpm test:coverage` 生成，LCOV 文件作为 `runtime-coverage` artifact 上传。范围是核心注册器、绑定运行时、SSR 和序列化源码；不把这个比例误当成 Vue/Svelte 编译器或浏览器整体覆盖率。框架和浏览器用例独立验收。

可以在首次登记前配置 `configureCss({ warnAfter: 50_000 })`，总规则数达到提示线时只警告一次。此选项默认关闭，不阻止继续登记，不删除历史类；按项目实际规模设定，结合 `cssStats()` 区分普通类和活动绑定。无意义状态更新、相同内容命中和变量值更新不会被误算作增长。

Vue KeepAlive 停用期间保留该实例的绑定，重新激活复用规则，最终卸载时清理。Svelte SSR 的保留/清理由服务端包入口决定，不受测试环境是否模拟 document 影响。
