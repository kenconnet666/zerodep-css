# 混合样式框架生产化执行计划

用户于 2026-09-22 授权进入无人值守目标模式：代理自行规划、实现、审查、修复和分阶段提交，完整回归由 CI/CD 执行，直到整个产品在明确支持范围内生产可用。目标不限于此前讨论的功能清单，常规决策不再询问用户。

## 当前决定

- 保留 core/vue/svelte 三个产品包，运行时是正式能力，复杂结构和不能安全预编译的代码有正确的回退路径。
- 新作者路径使用编译器自动分离动态属性值，移除公开 bx；不是把未知表达式默认为静态或悄悄丢绑定。
- 系统关键字、主题 token 和静态样式尽力预准备；可证明正确的 if/switch 分支可以优化，不能改变原生求值顺序、作用域和副作用边界。
- 类型与主题扩展采用真实 `class AppCss extends Css`。不默认引入 recipes/variants；主题覆盖通过继承与应用/组件作用域表达。
- s.name 为根样式提供可读身份，开发来源不进入语义哈希。s.config 首版仅接入经实现证明有实际用途的封闭配置，不做任意配置袋。
- 保持 css 返回字符串、CSS 属性对象不可调用，以及严格 token、开放 raw、单位方法的作者合同；响应式和 SSR 所有权使用框架原生机制。
- 保持 private，完成独立安装和生产构建验收。生产可用不等于自动公开发布或更改仓库许可；外部发布仍不是本轮动作。

## 交付阶段

1. **工程基线与诊断闭环**：固化目标和测试门槛，将完整 CI 跑起来；整理编译器/命令工具目录，把产品编译代码纳入类型检查，补充审查复现。
2. **运行时基础**：建立统一的声明/格式化与绑定描述边界，实现数值快路径、有限缓存、可复用静态样式和必要的注册优化，保留严格校验、事务、全局槽位与恢复合同。
3. **作者继承、命名与主题**：完成 Css 派生类型的实际实例语义、命名/配置和诊断信息，主题继承及局部覆盖，避免共享请求状态与类型/runtime 脱节。
4. **自动编译与回退**：移除公开 bx；Vue/Svelte 原生值绑定、分支/嵌套/循环/帮助方法、可用的静态准备和有限分支优化。不能证明等价的路径保持运行时语义；无法安全支持的边界明确诊断。
5. **生产消费与全栈审查**：独立 tarball、官方 Vite 客户端/SSR/HMR、源码映射、错误恢复、CSP/目标容器、主题隔离、资源清理、依赖与包体积验证。修复本轮及新发现的缺陷。
6. **最终验收与交接**：核对最终提交的完整 CI、声明和安装边界、文档示例及支持矩阵；无影响支持范围的已知高优先级缺陷后才结束目标。

阶段可以因依赖关系适当细分，但不能为了提交而留下失效的入口或过渡失败状态。每次提交使用中文说明，保持聚焦且可审查；保留已有未关联改动，不重写远程历史。

## 验证策略

- 本地：修改对应的类型检查、根构建、原生 LSP 与针对性单元/小型组件验证；不用反复执行全套浏览器和独立消费者安装替代 CI。
- CI：锁定安装、格式/生成一致性、类型、构建、快速测试、完整 LSP/类型负例、浏览器、SSR/hydration/HMR、独立消费者、体积与泄漏检查。按 job 构建一次，后续使用 --no-build。
- 持续读取实际 CI 结果并处理失败；workflow 文件存在或推送成功不等于验收通过。
- 新增对 fallback、动态值、主题树、命名、错误路径、实例隔离和组合覆盖的正反例。类型检查通过不替代语义执行结果。
- 性能声明以可复现数据为准，分别报告格式化、规则生成、DOM/布局、包体积；不把微基准当作完整应用 FPS。

## 完成标准

- 系统/主题 token 可复用，动态值无需公开 bx，结构性和复杂样式具备有效运行时路径。
- 同一状态重复使用不重复解析/注册；动态值更新不无界新增 class；必要的缓存有明确边界和所有权。
- 继承、主题覆盖、name/config 的类型与运行时一致，生命周期和 SSR 请求隔离有自动测试。
- Vue/Svelte 的源码位置、作用域、模板守卫和正常编译/HMR 保持正确；所有公开入口均可从独立安装使用。
- 全局样式、动画资源、目标容器与恢复在错误路径上不会留下错误成功标记或破坏其他 owner。
- 文档准确区分支持、回退、诊断和非目标范围；产品构建不依赖本机绝对路径或研究仓库。
- 最终工作区无临时产品改动，阶段提交已推送，最终 CI 成功且对应当前实现；完整交接记录可直接用于继续维护。
