# 生命周期和定位

组件的 bx 绑定由 Vue / Svelte 生命周期管理。卸载时停止订阅并删除该组件的私有值规则；named globalCss 块和普通样式类属于文档 / 请求宿主，组件卸载不自动删除它们。

```ts
const stats = cssStats();
// rules：总数；classes：普通类；animations：动画；
// globals：命名全局块；bindings：私有值规则；connected：主标签是否连接。
```

`bindings` 不等于当前 DOM 元素数。列表更换 key 后，旧 frame 仍保留到所属组件卸载，因为返回的 class 字符串可能被其他位置保存。需要长期轮换大量数据时，优先使用有独立生命周期的行组件，避免将所有历史 key 都留在一个永久存在的父组件中。

普通类和动画按内容缓存。带实例私有变量的类包含实例身份，反复创建新实例会增加普通类记录，即使卸载后 bindings 已回到 0。库不按缓存年龄擅自删除这些仍可被外部字符串引用的类。`disposeCss()` 只用于整个宿主退出；不能在任意路由 / 子组件卸载时调用，以免破坏其他活动组件。

真实 Vite HMR 的模板更新、脚本更新、删除动态声明和修改选择器由 CI 验证。测试使用独立临时应用，不修改用户正在运行的项目；测试结束关闭自己的服务器、浏览器并清理目录。热更新应保留其他组件样式，且不增加重复活动绑定。Vue 与 Svelte 的组件热替换机制不同，不要求它们产生相同数量的历史类。

构建回退提示包含 `文件:行:列`。开发构建的运行时覆写提示也包含作者调用位置；生产代码不携带位置字典。source map 保留未修改语句的位置，改写调用中的辅助代码映射到相应原始片段。

当前耗时验收由 CI 执行：真实 HMR、30 次挂卸、列表 key 轮换、200 / 1,000 项性能对照、Nuxt / Kit 的 SSR 与静态部署。`runtime-diagnostics` artifact 保存计数与计时。时间只供比较和选型，不作为硬阈值；不能把“未重复写 CSSOM”解释为“完全不再执行 JS”。
