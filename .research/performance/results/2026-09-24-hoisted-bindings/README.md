# 单声明响应式提升的浏览器原始样本

旧版为 `ac6d035`；候选为本记录所在提交的产品代码。旧版经 Git archive 置于独立临时目录，按相同 `pnpm-workspace.yaml` 锁安装、构建；候选在原工作区构建。两边的 benchmark 脚本、`pnpm-lock.yaml` 与浏览器依赖相同，锁文件 SHA-256 为 `9cad5e77f64c8096a24630deddb6d4c29abd12dd66415d1784279817e28cc1d9`。

按“当前 A → 旧版 A → 旧版 B → 当前 B”串行运行 `pnpm research:compare`，不与其他压测并行。每份报告的 Vue/Svelte 场景均对 200 元素轮换顺序执行 5 轮，取中位数；有限值场景 30 批更新，全新值场景 5 批更新。更新计时含框架调度和每批布局读取，不含网络、初次 JS 解析和构建。`current-*.json`、`baseline-*.json` 保留完整轮次、挂载、规则数、框架版本、验证状态与运行 ID；`pnpm-lock.yaml` 保留精确依赖。

| 框架   | 场景           | 旧版 A / B (ms) | 候选 A / B (ms) | 规则数 |
| ------ | -------------- | --------------: | --------------: | -----: |
| Vue    | 16 值自动变量  |    95.6 / 103.8 |    82.2 / 116.5 |      1 |
| Svelte | 16 值自动变量  |   120.4 / 126.5 |     79.3 / 88.3 |      1 |
| Vue    | 全新值自动变量 |     18.2 / 18.9 |     13.7 / 17.3 |      1 |
| Svelte | 全新值自动变量 |     20.7 / 21.6 |     13.5 / 14.4 |      1 |

Svelte 的两个候选报告在这两种负载下均低于旧版。Vue 候选 B 中原生变量、Emotion 固定变量和本库运行时对照也一起变慢：例如原生变量由同轮旧版 B 的 58.4 ms 到候选 B 的 74.6 ms。因此不能用四个绝对数计算统一提速；有限值自动绑定除以同轮原生变量的比例由旧版 1.63/1.78 到候选 1.41/1.56，仅说明受控场景有改善迹象。全新值候选仍是一条规则，对照的纯运行时新规则仍为 1400 条。

此样本的优化命中来自同 SFC 中的简单 `css(s => s.width.px(value))`。实际跨模块项目 hook、复杂回调和多属性声明通常仍走其他路径；不能把这里的数字推广到整页或启动时间。运行时 class、raw/token 回退、主题、SSR/hydration 与列表更新另由针对性测试验证。
