# 生产使用与支持范围

框架保留运行时 CSS：作者字段和方法生成声明字符串，css 组合并缓存规则。bx 是可选编译能力，明确把表达式变成 CSS 变量；不用 bx 时不依赖变量转换。最新验收提交、完整任务结果和实测数据见 [执行记录](production-progress.md) 与 [性能记录](performance.md)。

## 当前交付范围

- 五个 private 工作区包：core、vue、svelte、nuxt、sveltekit，包间 workspace:*，尚未发布到 npm。
- 验收锁定 Node 24、pnpm 10.34.5、Vue 3.5.43、Svelte 5.57.0、Nuxt 4.5.2、SvelteKit 2.70.3。peer 范围用于依赖兼容声明，实际验收版本以锁文件与 CI 为准；升级后应重跑完整矩阵。

- Vue script setup 与 Svelte 实例脚本的 JS/TS，模板 class、列表、派生值与同步框架侦听回调；具体作用域见 [bx](bindings.md)。
- 标准 Node SSR、请求隔离、hydration、客户端导航、Nuxt/Kit 静态预渲染及 nonce CSP。
- 502 个系统/SVG 属性、单位与颜色/数学方法、原生嵌套选择器、动画、命名全局规则、类组合、可选亮暗主题与项目继承。

## 推荐组织方式

在项目入口用 createCssContext<AppCss>() 定义并导出 provideCss/useCss。根组件提供一个作者实例，后代复用；服务端按请求创建宿主和项目作者实例。纯系统 Css 不携带主题，需要时继承 ThemeCss，再继承项目自己的属性类。

有限状态使用普通 if/switch/条件表达式或共享静态类；连续值使用 bx。单位由作者明确提供：s.width.raw(bx(width + 'px'))，或 s.width.calc(bx(width) + ' * 1px')。bx(12) 只产生值为 12 的变量，不推断单位。常量也生成变量，但无需额外响应式订阅。

css 始终组合声明和当前宿主已经登记的样式类。外部 class、className 标记和框架条件对象交给模板 class 组合。keyframes/globalCss/选择器支持嵌套数组与条件空项，但不把字符串当成样式类展开。声明覆盖遵循原生 CSS。

## 生命周期与资源

私有绑定的类可以转发给子组件，在绑定所有者存活期间有效。所有者退出时停止订阅、清理值规则，并回收不再拥有活动绑定的私有类和动画；仍有其他活动绑定的组合继续保留。普通静态类、静态动画和命名全局块仍由宿主缓存；删除全局块用 globalCss(name)。

KeepAlive 停用保留实例和绑定，重新激活复用，最终卸载才清理。同一长期存活组件不断换全新的列表 key，历史绑定帧仍保留到组件卸载；长期滚动/分页列表应按行组件划分生命周期。configureCss({ warnAfter: 50_000 }) 可提供一次性增长提示，默认关闭，不阻止登记。详见 [生命周期与诊断](lifecycle-and-diagnostics.md)。

## 明确的边界

- 原生 CSS 的解析、无效值和层叠交给浏览器。raw 和 bx 不承担任意 CSS 的安全过滤；应用负责传入合适的值。
- bx 是组件构建标记；普通跨文件工具函数可接收已绑定的字符串，但不自动转换其内部的 bx。Vue Options API、手写 render/JSX 中的 bx 不属于当前宏范围。
- 被遮蔽的嵌套循环别名不能保证自动绑定；使用不同别名或独立行组件。scoped slot 推荐稳定对象参数，连续变化的原始值参数会产生新的绑定身份。
- 同步 computed/watch/effect 支持稳定绑定帧；异步回调跨 await 的部分不保证同一帧。Svelte effect 保持原生的客户端时机，SSR 首屏需要在 setup 提供初值。
- 主题按真实 DOM 继承。Teleport/portal 移到主题边界外后，不会自动复制主题。
- 流式 SSR、边缘运行时、Shadow DOM 和跨宿主微前端合并尚未纳入本轮验收。运行时 css 本身仍可在已配置宿主的普通函数中使用。

这些边界是使用契约；不通过删测试、放宽为任意值或静默改变 CSS 语义来掩盖不支持的场景。

## 验收与维护

CI 并行运行 15 个任务：两平台基础检查、源码/编译器与包测试、三浏览器、两框架生命周期、两元框架、四组性能，以及生产依赖高危审计。源码覆盖率报告只对应列出的核心运行时文件，框架编译、类型与浏览器另外验收。

每阶段中文提交并推送；本地运行改动相关检查，耗时浏览器/性能/元框架交给 CI。推送后继续工作，下次提交前检查上次结果。pnpm css:generate 是修改生成属性的唯一入口；没有引入 Proxy 作者模型、属性类型泛型链或另一个同义 API 系统。
