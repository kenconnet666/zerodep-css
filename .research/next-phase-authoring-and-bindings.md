# 下一阶段：作者 API 与隐式响应式绑定

状态：讨论结果与实施计划，尚未实现。承接[运行时库审查](runtime-library-tradeoffs.md)；用户随后明确要求把下列 API 和隐式绑定一并纳入，因此本计划更新了审查稿中“暂缓 cx / 动画 / 全局样式 / 编译绑定”的建议。

## 已确认的方向

- 保留运行时 CSS、原生控制流和 `class AppCss extends Css` 扩展方式。
- 属性字段与方法继续返回声明字符串，`ic()` 返回规则片段，普通 `css()` 返回类名。
- 全局样式采用有名字、可更新和移除的规则块。
- 合并入口只叫 `cx`，语义参考 Emotion，不另外提供同义 `merge`。
- 子类名采用独立命名标记，由 `ic()` 引用；标记函数暂沿用推荐名称 `className`。
- 动画采用 `keyframes(ic('from', ...), ic('to', ...))`，返回动画名称字符串。
- 单位、颜色、数学函数优先通过属性方法补强，保持完整声明字符串模型。
- 不增加公开 `var()` 方法。用户直接写 Vue/Svelte 响应式变量，由适配器构建转换生成隐式 CSS 变量绑定。
- 一条声明中的多个响应式值属于基础范围，包括多个参数、多个模板插值、同一变量多次出现及不同单位复用。
- 简洁、高效、容易人工维护优先；不添加运行时 CSS 值解析器，不复制 Emotion 的全部输入 DSL 或插件生态。

## 目标 API

以下示例含尚未实现的方法。

### 单位与属性函数

```ts
s.width.rem(20);
s.height.dvh(100);
s.padding.rem(0.5, 1);
s.gap.em(0.5, 1);
s.width.percent(50);
s.animationDuration.ms(180);
s.rotate.deg(45);
s.color.rgb(255, 0, 0);
s.width.clamp('16rem', '50vw', '40rem');
s.padding.raw('8px 1rem');
```

长度单位覆盖字体、视口、动态视口、容器和绝对长度家族；百分比、时间、角度按属性实际能直接接受的值类型生成。普通属性保持单值，简写按自身语法提供参数数量，不能只因为某个嵌套 CSS 函数内部接受长度就给整条属性添加长度方法。

生成器负责能力元数据、参数签名、中文提示和方法名冲突检查，不手改 502 个生成类。单值路径继续直接格式化字符串，多值简写才组合多个参数。复杂值始终可使用 `raw()`；不新增 var、pct/percentage 等平行别名或一套独立值对象 DSL。

### 全局规则块

```ts
globalCss('app-base', ic('html, body', s.margin.px(0)));
globalCss('theme', ic(':root', '--brand:red;'));
globalCss('theme', ic(':root', '--brand:blue;'));
globalCss('theme', ic(':root', '--brand:red;'));
globalCss('theme');
```

同名更新整块替换且保持插入位置；空规则列表移除该块。移除后重新创建按新建处理，作为本阶段推荐的补充约定。所有权属于对应宿主和命名块，不能拿普通类的历史去重阻止红→蓝→红。全局块可以利用原生样式文本解析，不为拆分多个顶层规则引入 CSS 解析器。

### cx 与独立标记

```ts
const title = className('Card.title');
const root = css(ic(`& > .${title}`, s.fontWeight.bold));
const base = css(s.color.red);
const active = css(s.color.blue);
const child = cx(title, base, enabled && active, ['external', { disabled }]);
```

`cx` 整理字符串、嵌套数组和条件对象，忽略布尔值、null、undefined。按顺序取回当前宿主已注册类的声明；少于两个已注册类时不额外生成规则。其他类名与独立标记原样保留；两个及以上已注册类才合成新类。保留原生 important、简写、长属性和选择器关系，不删除前面的属性，也不承诺覆盖外部 CSS。

独立标记按明确名称确定，生成时不注册 CSS，可作为模块常量；不依赖全局递增计数器。标记不是样式类，`cx` 重组样式后也保留它，父级选择器不随声明内容变化而失效。

### 动画

```ts
const fadeIn = keyframes(ic('from', s.opacity.raw(0)), ic('to', s.opacity.raw(1)));
const item = css(
  s.animationName.raw(fadeIn),
  s.animationDuration.ms(180),
  s.animationTimingFunction.easeOut,
);
```

相同内容复用名称，内容变化产生新的定义；时长、缓动、方向、次数与播放状态继续走 CSS 属性。帧选择器仍用 `ic`，不新增同义 frame 入口。登记、SSR 与恢复共用基础设施，不给三类规则各写一套缓存。

## 隐式绑定：多表达式是基本能力

Vue 目标写法：

```ts
const x = ref(12);
const y = ref(8);
const angle = ref(15);
const top = ref(0.5);
const side = ref(1);

const box = css(
  s.padding.rem(top.value, side.value),
  s.transform.raw(`translate(${x.value}px, ${y.value}px) rotate(${angle.value}deg)`),
);
```

Svelte 对应写法直接读取 `$state` / `$derived` / props 值，不要求 `.value`、getter 包装、变量名字或手工 style 绑定。

转换需要保留表达式与作用域，不能在普通函数已经收到数字后猜测其来源。core 保持框架无关；Vue/Svelte 的构建与运行时适配分别承接依赖追踪、DOM 绑定和初值输出。Nuxt/SvelteKit 集成接入对应转换，普通框架项目使用相应构建插件。

多个绑定的要求：

- `padding.rem(top, right, bottom, left)` 等一条声明中的多个参数分别响应更新。
- `rgb(r, g, b, alpha)` 等多个通道，以及 raw 模板中的多个表达式，全部保留依赖。
- 同一响应式变量同时用于 px 与 rem 时，格式化结果不能错误复用。
- 必须绑定完整 CSS 值片段；不能输出无效的 `var(--x)px`。
- 已知属性方法可以按参数槽位生成多个变量。任意复杂 raw 表达式可绑定整个求值结果，避免通过猜测 / 解析任意 CSS 字符串拆插值；整值绑定仍须追踪其中全部响应式依赖。
- 静态内容、普通初始快照与框架的 untrack 等语义保持；不擅自扩大响应式范围。

两个组件实例、列表项、同一辅助函数的多次调用不能共享“最后一次值”。变量的作用域必须对应实际使用位置；不能只建一张 className→最新值的全局表。

`cx` 合并不能丢绑定关系，也不能改变静态类名字符串契约。动画帧中的动态值需要作用到实际使用动画的元素。全局规则块的动态值单独验证其宿主范围，不能误写到任意局部组件根。它们均列为绑定探针与集成验收项，未通过前不得宣称已支持。

选择器、media 条件和规则结构变化保留原有运行时路径；不把结构当作 CSS 变量值。无法可靠转换的辅助函数或用户覆写方法不擅自改写，需明确诊断和支持边界。回退保留原来的求值时机，不能声称未经转换的 const 初始化会自动响应更新。

接受 CSS 变量本身的原生语义，值有效性由浏览器处理，不为了模拟直接声明的无效值回退而增加验证层。

## 实施顺序

1. **先验证绑定方案。** 在 Vue/Svelte 各做小样板，覆盖多参数、raw 多插值、单位、列表、cx、动画和全局作用域，确认如何保留表达式与绑定信息。早期解决接口风险，不等新增 API 全写完后再接绑定。
2. **完善登记基础。** 固化已有碰撞和 Unicode 用例，选定更宽的确定性哈希；新规则不重复哈希，保留插入失败可重试与清单原子恢复。以小而明确的规则种类承接类、动画、命名全局块。
3. **扩展作者生成器和公开 API。** 增加单位及选定的颜色 / 数学方法，实现 cx、独立标记、keyframes、globalCss；同时完善类型提示和注释，避免同义入口。
4. **正式接入隐式绑定。** 固化前期可行方案，集成 Vue/Svelte 构建流程和 Nuxt/SvelteKit。保持静态热路径，不要求预提取全部类名，不改变普通 JS 控制流。
5. **补齐宿主边界。** 实现最小 nonce / 插入位置配置，明确失联诊断、重建和清理；端到端验证 SSR、绑定值和 CSP 的组合，不把 style 标签有 nonce 当成全部场景已通过。
6. **收敛验收与文档。** 共享可运行示例覆盖所有新能力，做相关性能诊断；本地焦点测试，远程完整矩阵。中文分阶段提交，每次提交推送。

## 关键验收

- 普通声明仍是字符串；不为静态关键字增加 Proxy、描述对象或运行时解析。
- 全局块反复更新、移除重建，最终层叠顺序正确；并发请求不串全局状态。
- cx 的条件输入、嵌套数组、外部类、独立标记和已注册类组合均符合约定。
- keyframes 去重、多个实例、动态帧值、SSR 恢复与后续更新正确。
- 单声明多变量：分别变化、同一轮同时变化、同变量不同单位、重复引用、混合静动态、复杂表达式。
- 多元素 / 多实例 / 列表项分别绑定；类名传递及 cx 路径不丢值或串值。
- SSR 首屏已有正确变量初值；hydration 不重复写规则或覆盖另一实例；连续值更新保持静态规则数量稳定。
- 原始运行时分支仍可使用；不支持的转换位置有明确边界，不能静默冻结本应更新的值。
- 性能区分静态命中、有限状态与连续新值，比较绑定路径和框架原生手工绑定；不把一次微基准的比例当成页面收益。

本文件固定本轮讨论范围，不表示其中任一新 API 或绑定转换已经落地。
