## 内置预设

- 提供 lightTheme 和 darkTheme 共两套语义主题，暗色通过亮色预设继承，变量身份和 schema 一致。
- 通过独立 themes 子路径按需加载，不让仅使用 core/Css/cssVar 的应用初始化预设或增加默认入口体积。
- Css 基类继续只提供系统 CSS；可选 ThemeCss 子类提供语义颜色及常用 token 的作者便利，用户仍可以继续继承。
- 配色包含画布、表面、文本层级、主色/辅助色、成功/警告/错误/信息、边框与焦点，并给出两套阴影和共享尺度。
- 文本与背景、强调色与其前景色进行独立 WCAG 对比度计算；真实组件验证亮暗同时存在、动态切换、局部覆盖、SSR/hydration 和三引擎结果。

## 追加验收

1. 全部预设 token 类型、名称冲突、值域、冻结/继承、覆盖重置与变量身份。
2. 多状态动态值的编译/运行时对照、空值/CSS-wide、重复声明、嵌套/守卫、不同实例与跨目标边界。
3. 缓存预算与大输入、失败重试、资源事务、销毁/重建、并行 SSR、主题同名冲突与外部对象变更。
4. 可访问性对比度、可读默认颜色、亮暗混合显示，以及快照和实际计算样式。
5. 独立安装、公开入口/类型、源码地图、默认包体积和全套 CI；不以新增几个 happy-path 测试替代审计。

完整长测试继续交给 CI/CD，本地运行类型/构建和新增缺陷对应的关键测试。发现回归时先补独立复现，再修复；不保留已知缺陷来满足预定结束时间。
